# Origin EPG Proxy

Automated high-performance EPG pipeline for **Stremio Origin**.

- Sources parsed: EPGTalk (45MB XML), Open-EPG Egypt/OSN/Arabic, and beIN Sports.
- Generates a static `epg.json` updated every 4 hours via GitHub Actions.
- Hosted on GitHub Pages CDN with 0ms serverless cold-start and zero rate limits.
